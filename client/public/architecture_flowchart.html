2. Core Subsystems & Components

Layer Component / File Primary Functionality Underlying Technologies
Frontend App.jsx Global state orchestrator, persistent tab management, session history drawer. React 19, LocalStorage
Frontend MathText.jsx Tokenizes mathematical expressions and renders KaTeX LaTeX formulas. KaTeX 0.16, Regex
Frontend BlueprintDesigner.jsx Custom question counts, sub-question structure, and Bloom's HOTS coverage report. React, Pure CSS Bar Graphs
Frontend AnswerEvaluator.jsx Grades student handwritten/typed answers with partial credit rubric. Gemini Vision, FormData API
Frontend PaperAnalyzer.jsx Historical question paper mapping, recurrence heatmaps, and exam forecasting. pdf-parse, Gemini AI
Frontend QuestionVariants.jsx Generates structurally diverse examination question variants (Sets A, B, C). AI Variation Archetypes
Frontend QuestionLab.jsx Collaborative Question Bank, custom tagging, 5-star ratings, JSON import/export. Blob API, FileReader, LocalStorage
Frontend FlashcardDeck.jsx Interactive 3D study cards, WebSpeech TTS audio playback, Anki TSV export. CSS 3D Transforms, Web Speech API
Backend server.js REST API, static bundle serving, and AI prompt orchestration. Node.js, Express, Multer
Backend generateWithFallback() Multi-tier model fallback (gemini-3.6-flash ➔ 3.5-flash ➔ flash-lite ➔ pro). @google/generative-ai
PWA sw.js & manifest.json Offline caching and desktop/mobile installation ("Add to Home Screen"). Cache API, Web App Manifest
